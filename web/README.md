# Trascrvibe UI

Trascrizione **locale** di file audio e video.

## Funzionalità

- Caricamento di file audio/video con drag & drop o selezione
- Scelta lingua (o rilevamento automatico) e modello Whisper
- Dashboard dei lavori con stati: in attesa, in elaborazione, completato, fallito
- Trascrizione modificabile per segmenti, con salvataggio
- Player sincronizzato: clicca un timestamp per spostare la riproduzione
- Interfaccia bilingue: italiano e inglese

## Sviluppo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
